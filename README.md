# SleepSplit

SleepSplit is a Python application for splitting long MP3 audiobooks into
smaller listening segments.

The primary goal is to create segments that are well suited for bedtime
listening while preserving audio quality through lossless processing.

---

## Purpose

Many audiobooks contain very long chapters that are inconvenient for bedtime
listening.

SleepSplit was created to automatically divide audiobooks into shorter,
more convenient listening segments while keeping the original audio intact.

## Features

Planned features include:

- Lossless MP3 splitting
- Automatic silence detection
- Configurable target segment length
- Batch processing of complete audiobook collections
- Metadata preservation
- Cross-platform command line interface
